Venus is now "Overtime" — a day there outlasts its whole year, so the planet never clocks out. Venus spins so slowly that one day (243 Earth days) is longer than its entire year (225 Earth days): the one planet in the solar system permanently stuck on the clock.

## Run it

```sh
node main.ts
```

It writes the one-line entry to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
